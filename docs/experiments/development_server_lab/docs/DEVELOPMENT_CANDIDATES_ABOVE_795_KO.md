# 79.5% 초과 모델의 후속 개발 후보

2026-10-03. 기존 팀 실험 보고와 사용자가 전달한 D계열 서버 결과를 근거로 선별했다.
후속 방향은 실험 제안이며 아직 관측된 개선으로 표현하지 않는다.

## 기준

79.5는 Valid20의 **D4 mIoU 0.795 초과**로 해석했다. 역사적 R계열은 absent=1 이미지 macro 지표다.
이 수치는 픽셀 accuracy나 공식 Test 성능이 아니다. Strict 지표 또는 single 기준이면 선별 목록이 달라진다.
D계열은 전달 보고의 D4 값이며 평가 구현·환경을 역사적 R계열과 동일하다고 가정하지 않는다.
현재 RRCU/scSE R01–R03은 완료 결과가 없어 선별 대상에 넣지 않는다.

R022가 모든 seed에서 안정적이라는 결론은 아니다. seed42/43 두 기록이 있고 두 번 모두 문턱을 넘었다는 뜻이다.
R024/R039는 기준을 이긴 모델이 아니다. 별도 구조의 발전 가능성 및 오류 상보성을 확인할 조건부 후보다.
특히 R024는 backbone뿐 아니라 pretraining과 detail skips도 달라 encoder만의 효과로 해석하지 않는다.

D03은 Eutectic IoU −0.2287pp 및 precision 감소가 있어 접촉부 오류 감소만으로 채택하지 않는다.
추가 seed 비교에서는 전체 mIoU, 두 상의 IoU, Eutectic precision/recall, skeleton recall, 접촉부 오류를 같이 확인한다.
이미지 bootstrap 95% 구간 −0.304~+0.479pp는 0을 포함하며 학습 seed 변동을 측정한 결과가 아니다.

## 관측 최고 및 낮은 우선순위

- R031 79.9332%: seed42 관측 최고. 타일별 Dice 변경의 seed43 R033은 79.4814%이고 같은 seed B(R032)보다 −0.2712pp다. 두-seed 평균 차이는 −0.1175pp. 최고 checkpoint는 보존하되 기본 loss를 이 설정으로 교체할 근거가 부족하다.
- R035 79.7864%: encoder BN 통계 고정. R022 대비 −0.1105pp. batch4에서 안정성이 실제 개선됐다는 추가 근거가 없어 성능 개발의 우선 후보로 넣지 않는다.
- R023 79.6613%: ResNet152. R022보다 낮아 단순히 encoder를 더 깊게 만드는 방향의 우선순위는 낮다.
- R029 79.7563%: 최종 DySample. R022 대비 −0.1407pp. 기존 설정의 확대 적용 근거 부족.
- R041 79.7239%: 전체 경계 CE 가중. R022 대비 −0.1731pp. D03과 다른 설계이며 현재는 접촉부를 특정한 D03이 더 직접적인 후보다.
- R027/R036/R037/R043/R044는 문턱을 넘겼지만 각 변경이 R022보다 낮았다. 가중치 완화/OHEM/crop jitter/scSE 제거/Dice 제거를 우선 결합하지 않는다.
- D01 79.7461%, D02 79.6669%: 전달 보고상 D01은 Eutectic 누락 증가, D02는 접촉부/가는 조직 개선 실패. 현재 설정을 D03이나 RRCU와 바로 합칠 근거가 부족하다.

## 개발 순서

1. R022/B 중심의 현재 RRCU/scSE 비교 결과를 확보한다.
