This package adds multiclass logits, center-only supervision, decoder scSE,
RSU residual-branch ECA, six-side pre-fusion CBAM, and matched-seed comparison.
It is an independent experiment implementation, not an exact reproduction of
the alloy-paper model, and contains no alloy-finetuned pretrained checkpoint.
