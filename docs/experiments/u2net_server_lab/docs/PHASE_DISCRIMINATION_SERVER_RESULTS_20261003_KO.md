## 판단 및 현재 실험과의 관계

이번 seed의 최고 후보는 D03이다. 재현 가능한 우위는 아직 확정되지 않아 기본 B recipe는 유지한다.
D03을 채택하려면 같은 서버에서 B/D03의 추가 동일 seed 비교가 필요하다. 이 문서 작성 때문에 그 학습을 새로 시작하지 않는다.
D01/D02 결합은 현재 결과로 뒷받침되지 않는다.

사용자가 앞서 별도로 요청한 RRCU/scSE 위치 비교 R01/R02/R03은 B에 각각의 변화만 적용한다.
대조학습/BEM/접촉부 loss는 해당 R계열에서 모두 비활성화한다. 로컬 MPS라면 서버 D계열 B와 직접 비교하지 않고
같은 로컬 코드/환경의 B를 다시 학습해 비교한다.
